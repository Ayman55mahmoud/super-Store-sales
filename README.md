# Power BI Sales Dashboard

## Description
An interactive Power BI Sales Dashboard designed to analyze sales performance, profitability, product quantity, customer trends, categories, monthly sales, and regional performance through dynamic visualizations and interactive analysis features.

## Tools
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization
- Dashboard Design

## Categories
- Power BI
- Data Analysis
- Business Intelligence
- Dashboards

## Business Problem
Sales data can be difficult to understand when it is spread across different dimensions such as time, customer segments, product categories, and regions.

This dashboard provides an interactive view of sales performance and helps users monitor key business metrics, compare performance over time, identify trends, and explore sales results from different perspectives.

## Key Questions
- What are the total sales, total profit, and total quantity?
- How does sales performance change over time?
- How does performance compare year over year?
- Which product categories generate the highest sales?
- Which regions contribute the most to total sales?
- How does customer count change across years?
- Which months have the highest sales?
- How can users drill down into specific data points?
- How can users explore additional details through tooltips and drillthrough pages?

## Dashboard Features
- Interactive KPI Cards
- What-if Analysis
- Drillthrough
- Custom Tooltips

- Interactive Buttons

- Interactive Charts
- Sales Trend Analysis
- Category Analysis
- Regional Analysis

## Methodology
- Reviewed and prepared the source data for analysis.
- Cleaned and transformed the data using Power Query.
- Built the required data model in Power BI.
- Created DAX measures for key sales and performance metrics.
- Calculated Year-over-Year (YoY) performance to compare results across years.
- Designed KPI cards to display total sales, total profit, and total quantity.
- Analyzed sales performance by category and region.
- Created monthly sales trend visualizations.
- Added What-if Analysis to allow users to interact with scenario-based analysis.
- Implemented Drillthrough functionality for deeper analysis of selected data.
- Created custom Tooltips to provide additional information without leaving the main dashboard.
- Added interactive Buttons to improve dashboard navigation and user experience.
- Organized the final visuals into an interactive Power BI dashboard.

## Key Insights
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Quantity: 38K
- Technology is the highest-performing category among the displayed categories.
- Sales performance varies across regions and time periods.
- The dashboard allows users to identify sales trends and compare performance dynamically.
